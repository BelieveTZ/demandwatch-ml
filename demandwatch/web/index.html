    What the stress test does

    The synthetic window adds 0.25 to prior normalized temperature (clipped to 0–1) and multiplies demand lag and rolling-mean features by 1.6. It tests monitor behavior on an artificial shift. Some values move closer to the autumn reference, so fewer alerts can result.

    Reading the numbers

    • The reference is the calibration window, not the training set.
    • 0.2 is this project's review threshold, not a statistical significance level.
    • Trend and calendar features can shift between windows by construction; expect non-zero PSI there.
    • Distribution change is a prompt to investigate, not evidence of error. Confirm with delayed labels and interval coverage.

    Methods

    What was actually run, and where the claims stop.

    Evaluation protocol

    • Exact chronological split. Train, validation, calibration and test are non-overlapping blocks in time order; boundaries are fixed before test scores are read and no shuffling is used.
    • Rolling one-hour-ahead evaluation. Each prediction is scored against the next hour using counts that had already arrived before that hour. This is not a 24-hour forecast from one fixed origin.
    • Lagged weather only. The model sees temp_previous, humidity_previous, wind_previous and weather_previous. Target-hour weather is excluded, so this is not an oracle-weather backtest.
    • Missing timestamps are excluded, not zeroed. The source is reindexed onto a complete hourly grid; lags and rolling windows are joined by timestamp, and rows without a complete feature vector are dropped rather than filled with zero demand.
    • No target leakage. casual and registered are dropped because UCI defines cnt as their sum; instant is an identifier, not a demand measurement.
    • Empirical intervals. A split-conformal radius is taken as the order statistic of absolute calibration residuals at rank ceil((n+1)·0.9), then applied symmetrically with a floor at zero. Coverage is measured on the test block after the fact.
    • Temporal dependence. Exchangeability does not hold for time series, so 90% is a target and a measured result, not a per-hour guarantee for future demand.
    • Reliance, not causality. Permutation importance reports how much held-out MAE grows when a feature is shuffled. It is an approximate diagnostic for a fitted model, not a causal effect.
    • Local CPU inference. Training and prediction run on CPU only; the fitted model artifact is persisted to local disk and loaded by the API. No external service is called at prediction time.
    • Monitoring scope. PSI compares a window against the calibration reference at a heuristic 0.2 threshold. Alerts indicate distribution change; accuracy loss must be confirmed with delayed ground-truth labels.
